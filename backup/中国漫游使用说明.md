# Lebara中国漫游使用说明

Lebara UK 在中国使用属于国际漫游。

中国是否包含在当前套餐、漫游附加包和具体价格中，应以使用当天的官方查询结果为准。

## 出发前准备

1. 在英国完成实体卡或 eSIM 激活；
2. 确认号码可以正常通话和收发短信；
3. 检查账户余额和套餐；
4. 查询中国当前漫游资费；
5. 记录 MyLebara 登录方式；
6. 确认重要账号还有备用验证方式。

> Lebara 官方明确要求，新 eSIM 服务需要在英国境内激活后再出国使用。

## 到达中国后没有信号

可以依次尝试：

1. 开启并关闭飞行模式；
2. 重启手机；
3. 确认国际漫游已经开启；
4. 将网络选择从自动改为手动；
5. 逐个尝试可用的中国运营商；
6. 等待数分钟重新注册网络。

## 无法使用移动数据

检查 APN：

- APN：`uk.lebara.mobi`
- 用户名：`WAP`
- 密码：`WAP`

同时确认已经购买适用于中国的漫游服务或账户内有足够余额。

## 资费提醒

- 英国本地套餐不一定直接包含中国漫游；
- 国际通话分钟不等于国际漫游分钟；
- 接听电话也可能收费；
- 后台流量和系统更新可能产生漫游费用；
- 旧教程中的价格和漫游范围可能已经失效。

# Lebara无信号或无法上网怎么办

## 一、检查基础状态

1. 确认 SIM 或 eSIM 已启用；
2. 确认手机没有锁定其他运营商；
3. 开启飞行模式后再关闭；
4. 重启手机；
5. 检查账户是否有余额或有效套餐；
6. 检查 SIM 是否因长期未使用而受限。

## 二、检查APN

如果有信号但无法使用移动数据，检查以下设置：

- APN：`uk.lebara.mobi`
- 用户名：`WAP`
- 密码：`WAP`

保存后选择该 APN，并重启手机。

## 三、在英国境外使用

请检查：

- 手机是否开启数据漫游；
- 当前国家是否支持 Lebara 漫游；
- 是否需要购买漫游附加包；
- 余额是否足够；
- 是否需要手动选择当地运营商。

## 四、无法收发短信

请先测试：

- 普通英国手机号码短信；
- 是否只收不到某个平台验证码；
- 短信中心和手机时间是否正常；
- 是否有足够余额发送收费短信。

某个平台没有发送验证码，不一定代表 Lebara 短信服务故障。

Lebara 官方已经确认部分 eSIM 用户可能收不到 Amazon OTP。如果只影响 Amazon，应联系 Lebara 客服登记问题。

## 五、仍然无法使用

从 Lebara 号码拨打：

> `5588`

也可以通过官网在线客服提交问题。
